# Cine Stream Next

A movie streaming web application built with Next.js.

## Features

- Display movie list
- Movie details page
- Unit testing with Jest
- React Testing Library integration
- Component testing for:
  - Button
  - MovieCard
  - MovieGrid
- Event simulation using userEvent
- Counter component for interaction testing

## Tech Stack

- Next.js
- React
- Jest
- React Testing Library

## Installation

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

## Run Tests

```bash
npm test
```
